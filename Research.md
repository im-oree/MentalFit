# Project Research( MentalFit  )

## 1. ONBOARDING
Onboarding should ask users for the following information in order:
- Goal( Losefat, Build Muscle, Health)
- Experience (beginner, intermeditae, advanced)
- Days in the week they'd be available , How many minutes/Hours they can work for 
- If they would be doing home workouts, gyming or a mix of home workouts and gyming
- Age, Name, Gender
- Weight, Height
- 3D AVATAR CREATION
- Adjust avatar to thier desired physique that they want to be

## 2. Excercises (AI Generated)
- Ai will generate a specific set of workouts for the desired user based on thier onboarding selections and if they choose to be mixed set of workouts they can select between (gym & home for each day) but for others that picked one they will be given only those ones and there will be rest days for those that days that the users specified that they wont have available during onbooarding.

- Each Excercise will have the users 3d figure demonstrating it for them and with opencv tracking we can monitor how the user does the excercise.

## 3. WORKOUT TRACKING
- **During**: during the course of an excercise we use threejs for 3D rendering to show the excercise and how to do it properly and it will have counters for Gyming days so you put in the weights.
